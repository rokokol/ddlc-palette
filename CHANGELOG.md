# Changelog

Kept in the shape of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), versioned by [semver](https://semver.org/spec/v2.0.0.html). A colour moving is a breaking change: everything downstream renders differently

## [Unreleased]

## [1.0.0] - 2026-08-13

Split out of [rokokol/huix](https://github.com/rokokol/huix), where the colours were literals scattered across the configuration

### Added

- `palette.json`: every colour with `hex`, `where`, `source` and the `method` it was arrived at, so any of them can be retraced
- `canonize.sh`, which re-reads ddlc.moe, and a weekly workflow that opens a pull request when the site has drifted
- `dist/`, generated by `generate.sh` and committed: base16 schemes, a JSON of bare hexes, an SVG of the palette
- `lib.palette`, `lib.bare`, `lib.rgba`, `lib.base16` and `lib.dist` as flake outputs, plus `overlays.default`
- checks that `dist/` is current, that every colour is annotated, that each base16 variant fills sixteen slots without spending a colour twice, and that the generators pass shellcheck and shfmt
